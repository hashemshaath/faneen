# qitaat

احتاج عمل موقع ودليل اكتروني احترافي لاعمال الالمنيوم ،الحديد والاستيل والزجاج ،الخشب والخزائن الاحترافية بحيث يكون مكان يبحث فيه الناس عن المصانع والمحلات ويكون هناك تقييم احترافي ومجتمع للتوصيات ومكتبة للاعمال والبيانات والوصول ومصة للعقود وانجاز العمل وتحمي حقوق البائع والمشتري ،ادخال خدمات التقسيط حسب توفر الخدمة لدى المزود ويمكن تسجيل الجهات ويوجد عضويات للجهات ،المستخدمين وسجل الاعمال و العقود والضمات وتقديم طلبات الصيانه والدعم وي،جد قسم للاعلانات واالاعمال ومعرض الفيديو والعروض الخاصة والمقارنه والتسعير وجودة العمل والجهات المصنفة والحاصلين على شهادت ،جوائز ،قسم المشاريع  / يجب الاهتمام باقصى درجة بالنمو وسرعة التصفح والو،ل والارشفة وتحليل السوق والقطاعات والتسجيل للاعمال والافراد ،الشركات / يجب ان يتم ب سيو والمحركات البحث الذكية ايضا ،الوكالات والاكسسورات وطلبها وعرضها وتقديم خدمات اخذ المقاس والتصميم ورفع الملفات ،قسم للمصممين  لتقديم خدماتهم بشكل احترافي اسم الموقع / اسم الموقع فنيين faneen والموقع الالكتروني faneen.com
