## 9. Day 2 Decision

### 🟢 Continue

اذا تحققت كل الشروط:

- لا توجد submit/upload failures.
- وصلت دعوات Tier A للمستهدفين.
- يوجد RFQ واحد على الأقل مكتمل (داخلي ناجح أو فعلي).
- لا توجد مشاكل خصوصية أو routes مكسورة.

الإجراء: مواصلة اليوم الثاني بنفس النطاق وزيادة الدفعة تدريجيًا.

### 🟡 Fix Before Continuing

إذا ظهر أي من:

- العملاء لا يكملون RFQ (drop-off عالي).
- المزودون لا يفهمون التسجيل/الـ onboarding.
- WhatsApp غير مضبوط ويُربك العملاء.
- زيادة في search no-results.

الإجراء: تجميد التوسع، إصلاح UX/تواصل في 24h، إعادة فحص قبل اليوم الثاني.

### 🔴 Pause

إذا ظهر أي من:

- فشل RFQ submit.
- فشل upload متكرر.
- public route مكسور.
- مشكلة خصوصية (تسريب بيانات عميل أو مزود).
- onboarding blocked تمامًا.

الإجراء: إيقاف الدعوات فورًا، فتح Issue P0، عدم الاستئناف قبل إغلاق الـ blocker واعتماد فحص جديد.
